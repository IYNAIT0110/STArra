# v0.6.8 新功能 · 贴点便签与新手引导

## 贴点便签

从侧栏选择重要程度，或使用自定义快捷键，在鼠标附近选择一档后输入。把便签拖到侧栏、功能面板或要跟随的其他窗口上。支持读取页面标识的浏览器可以按网页跟随，识别能力取决于浏览器。

右键已贴好的便签可截取它所在的屏幕。截图会标出便签原位置和文字，并直接进入「临时收件箱」。单击收件箱中的图片，可在 Windows 默认图片查看器里打开。

## 快捷键和录音

在「设置 → 快捷键」点击一条绑定，然后按组合键或在两次之间松开并快速连按同一个键。录音中可用「记下这一刻」或截图快捷键添加标记，回放时点进度条上的标记，查看对应的备注与截图。

## 重看新手引导

第一次进入工作区会出现快速上手。之后可以打开「设置 → 新手引导」，按章节学习或重播完整演示。Esc 可退出。

## 升级和清洁安装

安装器默认保留资料。只有主动选择「清洁安装」并确认，才会永久删除当前 Windows 用户的数据目录中的配置和资料。继续前可用胶囊备份并导出到其他目录。数据目录之外的原件和导出的备份会保留。
