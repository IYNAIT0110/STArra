# 临时收件箱 · 先收下，后来整理

从功能栏打开「临时收件箱」。可输入随手记、粘贴网址，或拖入文件、文件夹和图片。收藏气泡的「稍后整理」、按住 Shift 将文件拖到小球、星迹产物的「暂存到收件箱」都能直接添加。

- 网址可收藏到传送门。
- 随手记可保存到选择的星砂文件夹。
- 文件和 Agent 产物可导入已配置的百宝匣。暂存的本地文件和产物保存引用，归档前需要原文件仍可访问。
- 归档成功后条目才会从收件箱移除。也可以手动移除暂存条目。

收件箱保存在当前设备的应用数据里，独立于已归档的数据。目前胶囊不包含未归档条目。

## 截图批注与改图任务

在收件箱点「新建批注」，或从左侧选择已拖入的截图后打开「截图批注」。拖出框后就在图上填写对应批注。点击编号或文字可继续编辑，也可从图片工具区添加整图批注。编辑内容会自动保存。可以关联织梦台项目、当前文件或版本快照，再生成星笺任务。任务的「查看来源」会回到这张截图。改完后选一份改后版或上传新截图，标记为「待确认」。
