# STArra v0.6.3

## 星迹与外部 Agent

- 功能栏新增星迹。放大或缩小格点画布，查看调用方、工具、审批状态和产物。
- 在「查看流程」中按任务、对话或连接回放调用。支持单项删除和多选批量删除，已保存的产物会保留。
- 侧栏底部显示 MCP Agent 名称和连接状态。等待确认时可从该入口打开审批窗口。登录期间隐藏状态气泡。
- 卷轴使用 Chromium 生成 WebP 预览，保存原始图片。MCP 调用记录补充参数校验和文件操作的失败原因。

## 界面与交互

- 设置采用与其他功能一致的面板尺寸，新增功能命名切换和磨砂背景模糊调节。
- 调整小球、侧栏和功能面板的展开、收起与切换动画。
- 统一传送门链接卡片尺寸和功能面板边距。星笺的撤销提示会自动消失。
