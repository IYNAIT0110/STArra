# STArra v0.6.4

## 会议录音

- 在会议录音或录音历史中提取待办，查看结果后点击「写入星笺」，再确认写入。
- 支持识别的相对日期以录音当天为准。含糊的时间保留在备注中，供之后排期。

## 工作区

- 全局搜索改为功能面板顶部的胶囊搜索框，结果和预览显示在下方。
- 各功能面板的纵向滚动区域共用边缘渐隐。
- 活动中的灵动岛可长按拖出。原位凹槽可收起功能面板和最小化侧栏，拖回可归位。
- 拖放时保留连续的侧栏玻璃底板。倒计时启动、拖出和归位时保持主窗口位置稳定。

## MCP

- 同一连接身份跨会话保留头像和显示名称。
- 未连接时点击 MCP 状态栏，直达外部 Agent 设置。MCP 状态集中在连接栏显示。
