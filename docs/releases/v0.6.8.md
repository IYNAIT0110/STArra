# STArra v0.6.8

## 中文

- 本次更新的安装包提供中文、English、日本語选择。全新工作区使用竖向侧栏，依次播放快速上手和功能工作区。星砂按安装语言提供指南和示例，并移除了旧版 v0.6.7 功能介绍。

- **贴点便签**支持三个重要等级。快捷键在鼠标附近弹出等级选择；便签可跟随 Starra 或支持的应用窗口。对已贴好的便签点右键，把带位置和文字的截图保存到临时收件箱。
- **临时收件箱**里的图片可单击用 Windows 默认查看器打开。查看器打开时 Starra 临时让出置顶。
- **会议录音**支持截图标记和批注。回放时可通过进度条标记定位当时的截图与备注。
- **快捷键**可在设置里录入组合键或快速连按同一个键。**新手引导**在首次进入工作区时自动播放快速上手，也可从设置重播完整演示。
- 工具栏支持拖拽调整顺序，切换功能时保留页面状态。更新了便签卡片、星流聊天布局和下拉菜单。移除了屏幕顶部刘海吸附。

### 安装方式

常规安装默认保留资料。Windows x64 安装版提供可选的「清洁安装」，需要另行确认。它会永久删除当前 Windows 用户在 Starra 数据目录内的本地资料、配置和备份，重新打开后进入初始设置。外部原件和导出到其他位置的备份会保留。建议先通过胶囊把备份导出到数据目录之外。便携版没有安装选项。

## English

- The refreshed installer lets you choose Chinese, English or Japanese. A fresh workspace opens with the vertical sidebar and covers Quick start and Workspace tools. Star Sand seeds guides and demos in the chosen language.

- Pin notes in three priority levels and right-click a pin to capture its marked location and text into Inbox.
- Click an Inbox image to open it in the Windows default viewer. Starra yields its always-on-top position while the viewer opens.
- Add screenshot markers and annotations to recordings, and revisit them from the playback timeline.
- Customize key combinations or double-tap shortcuts. A first-run quick tour introduces the workspace, with the full tour and individual chapters in Settings.
- Reorder toolbar items by dragging. Workspace pages retain their state when switching tools. The top-edge notch has been removed.

Standard setup keeps existing data. Optional clean installation permanently removes this Windows user's local Starra profiles, settings and backups inside its data folder. Files and exported backups stored elsewhere remain. Export a Capsule backup outside the data folder before selecting this option.
