# STArra v0.6.0

STArra 是为办公人员和独立创作者设计的 Windows 桌面工作助手，帮助你随手记录、处理待办、找回资料，继续手上的工作。

## 本次更新

- **会议与快速录音**支持选麦克风、暂停与继续、边录边转写和导入音频。可在录音记录中回放、核对转写、提取待办，并手动保存到星砂文件夹或项目。
- **灵动岛**显示录音、待办提醒、专注计时和系统媒体状态。展开横栏时复用项目选择位置，收起时留在小球右侧。支持多提醒滚轮翻页、侧栏拖离与回嵌。
- **侧栏小工具**加入可刷新天气、可调时长的专注计时和媒体音量控制。播放暂停取决于播放器是否向 Windows 提供媒体控制。
- **星流语音输入**可将语音转成待确认的输入文本。可用的转写方式取决于当前配置。
- 更新了中英文产品介绍、使用指南和内置工作流。

## 从一件事开始

收到口头反馈时，先用快速录音捕捉内容。之后在录音记录检查转写，提取需要跟进的事项，将转写保存到星砂或项目。到点时可从灵动岛查看提醒。

支持 Windows 10 / 11 x64。安装新版前先退出当前运行的 STArra。安装包、便携版、文档包和 SHA-256 校验值见本页附件。
